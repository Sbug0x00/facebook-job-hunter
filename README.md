# 🚗 Auto-Post System - Phan Rang Taxi Service

Hệ thống tự động tạo nội dung và đăng bài lên Facebook Page mỗi ngày.

## 📋 Tính năng

✅ **Tự động tạo nội dung:**
- Chọn ngẫu nhiên tuyến đi hàng ngày
- Tạo giá phù hợp
- Thêm ảnh xe miễn phí
- Format chuyên nghiệp với hashtag

✅ **Đăng bài tự động:**
- Dùng Playwright (mô phỏng người dùng thực)
- Đăng nhập Facebook tự động
- Đăng bài lên Page
- Chạy mỗi ngày 7:00 AM (giờ Việt Nam)

✅ **Deploy trên GitHub Actions:**
- Chạy 24/7
- Tiết kiệm dung lượng (chỉ ~2 phút/ngày)
